1. DISPATCHER 0x0a8ff0 (LinuxLoader) = SW REV ANTI-ROLLBACK GATE
   Entry: x19 = request ctx. [x19,#4] selects class: 9 -> short path
   (0xa928c, ldr w20,[x20,#0x6c]); 0xb -> full image-name chain; else ->
   0xa9294 (cmp #7 ...). So 0xb = image-class requests (Odin flash list).

   First chain (0xa9048..0xa9270): guarded strcmp (bl 0x54bc, match =
   ret 0) against 29 image names in order: xbl, xbl_config, xbl_ramdump,
   abl, uefi, tz, hyp, devcfg, aop, shrm, cpucp, cpucp_dtb, apdp, qupfw,
   imagefv, bksecapp, vk, em, tziccc, hdm, keymaster, storsec,
   uefisecapp, tz_kg, apnhlos, secdata, sec, pit (+xbl again later).
   On match: w20 = [x20,#off] with a PER-IMAGE version-field offset
   (xbl 0x40, xbl_config 0x18, ramdump 0x64, abl 0x68, uefi 0x20,
   tz 0x58, hyp 0x5c, devcfg 0x24, aop 0x54, shrm 0x48, cpucp 0x4c,
   cpucp_dtb 0x50, apdp 0x44, qupfw 0x60, imagefv 0x2c, ...), w22 = 1,
   -> 0xa9338. Unknown name falls through to 0xa9270: cset w20,eq ->
   w20 = 0, w22 = 0 -> 0xa9338: cbz w20 -> DENY (0xa9494, w23 = 0).
   DEFAULT-DENY confirmed: nomes fora da lista reprovam.

   Second chain, only when [x19,#4] == 0xb (0xa9358+): compares
   [x19,#0x28] against apnhlos/pit/sec/secdata (-> 0xa94a4 digit-parse
   path at +0x88) and xbl special (x8 == 0 -> w1 = 0x36, bl 0xa8d70
   custom version fetch -> 0xa94e0). Non-matching xbl falls to
   bl 0xa8cb0.

   Version compare (both paths): 3 ASCII chars validated as digits via
   sub #0x3a / cmn #0xa / b.lo (C==0 iff NOT digit); all-3-digits ->
   w21 = 100*d0 + 10*d1 + d2 (mul/madd em 0xa94f0/0xa95e4); any
   non-digit -> w21 = 0. Then cmp w20,w21; b.ls -> DENY (w23 = 0).
   Return: w23 == 0 -> w0 = 0 (deny, 0xa95b4); else logs
   "[AR] RpVerOnFuse / SW REV CHECK FAIL : Fused %d Binary %d" and
   returns 1. Epilogue has stack-canary check (0xa95b8+).

   Verdict: hardened gate, default-deny, validated parse, canary.
   No length field from content drives a copy; offsets are per-image
   constants. NOT a memory-corruption surface. It is an OBSTACLE to
   downgrade attacks, not a primitive. Do not spend more here.
